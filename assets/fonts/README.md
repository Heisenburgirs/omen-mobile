# OMEN UI font

Static instances of Hubot Sans by GitHub and Degarism, sourced from Google Fonts. Width 112.5 (SemiExpanded), weights 400, 500 and 600, matching the supplied trading kit. Generated instances are named Omen UI to respect the original reserved font name. See OFL.txt.

Source: https://github.com/google/fonts/tree/main/ofl/hubotsans

2026-09-19: the barred zero (Hubot Sans draws a bar through `zero` and
`zero.tf`) is removed from all three files, so figures set in the UI face
read as a plain oval zero. The originals are in `.local/fonts-barred-zero/`.
