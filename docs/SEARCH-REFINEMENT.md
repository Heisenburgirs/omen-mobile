# Search refinement

Search is a single Stonk discovery list. The outlined, transparent search field and flat Volume / APR / Market cap controls stay above the scrolling list. Paste reads plain text only after a button press, trims it, and applies the same 80-character limit as typed searches. Empty or failed clipboard reads use a toast.

Rows use transparent backgrounds with no separator lines. Their second line shows the figure for the active sort (`$1.2M vol`, `202% APR` or `$6.5M MC`, the Stonk feed's own market cap), followed by the payout asset when known, for example `$6.5M MC  Pays ZEC`. FDV is never shown in rows. Missing values render as zero app-wide (`$0`, `0%`, `$0 MC`) instead of N/A.

Volume and Market cap sort using server-side values; tapping the active control again flips its direction (↓ highest first, ↑ lowest first), and the direction persists with the sort. APR sorts by an estimated yield computed locally for reward stonks: annualised transfer-tax revenue (24h volume × transfer tax × 365) over market cap. Only markets with at least $25K market cap are eligible, and at least $10K liquidity where the feed reports liquidity at all (it omits it for many large tokens), so thin launch-day tokens cannot dominate; ineligible or incomplete assets sort last in either direction, and the asset page shows the same figure labelled as an estimate; rows never display it. The list loads further pages automatically as the user nears the bottom (no page buttons); a new query or sort restarts from the first page. Detailed filters remain available from the unfilled filter icon. Filters and sort persist per OMEN wallet; the previous category preference and watchlist-only filter are retired.

Home's saved-assets preview opens a dedicated Watchlist screen, preserving saved assets of any supported Solana mint without a hidden Search mode. Asset details open on the existing route stack, retaining Search's scroll position on Back. No trading, wallet authority, or portfolio accounting behavior changes.
